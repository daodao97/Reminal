Closed-lid mode

No monitor. No dummy plug. No dongle.

Close a MacBook's lid and macOS puts it to sleep, unless it's on power with a monitor and keyboard attached. The usual fix is a hardware dummy HDMI plug that fakes a display, or leaving the lid propped open on your desk forever.

reminal does it in software. Flip it on and leave. It disables clamshell sleep and (because GUI apps need a screen to draw on) spins up a virtual display the moment the Mac goes headless, so window mirroring keeps working with nothing plugged in. Toggle it off and everything is undone.

Windows & desktops

        
Reach in and drive the apps.

        

        Any app window streams live into your browser, and you don't just watch it,
        you drive it.
      

      

      

        
    
        
  1. Click, type, scroll, drag. Right-click menus, pinch-zoom, text selection: the window answers exactly like it would under your own hand.
    2. 
        
  2. Nothing open yet? Launch any installed app on the host straight from the Apps menu, then drive it.
    3. 
        
  3. Or take the whole desktop. One tap on Host → View full desktop and the entire machine is yours.
    4. 
        
  4. On a phone, the screen becomes a trackpad. Your Mac, fully hands-on, from your pocket.
    5. 
        
  5. Or pop it out. The window leaves the tab and sits on your desktop like its own app window, an editor from your MacBook beside a terminal on a cloud box.
    6. 
      

      

    

    

    

    

      

        
60 fps

        
Nothing about it says stream.

        

    Drag a window, scrub a video inside it, watch a build scroll past: it stays fluid the whole way, on
    hotel Wi-Fi or a phone on cellular. Sixty frames a second, 17 ms from its screen to yours.
    H.264 down the session's own DataChannel, peer-to-peer, about 2.6 Mbps.
  

      

    

    

    

    

      

        
Terminal

        
And a full terminal, too. Scan a QR and you're in.

        

    reminal prints a session ID, a PIN and a QR code. Scan it and your phone is a real terminal
    on your machine: true colour, touch text-selection, on-screen modifier keys, find-in-scrollback.
    Close the laptop, switch device, reconnect from another city: the shell is where you left it, and the
    screen paints instantly.
  

      

    

    

    

    

      

        
Session dock

        
Every session, one swipe away.

        

    You're on one machine and need another. Drag the keybar's ≡ handle up and your live
    sessions fan out: every machine you own plus your recents, freshest first. Slide onto one,
    release, and you're connected: no IDs, no PINs, no typing. The shell is exactly where
    you left it.
  

      

    

    

    

    

      

        
Your fleet

        
Own your machines. Watch them all.

        

    Your machines don't stop when you walk away any more. Builds, patches and test suites run on
    hardware you aren't sitting at, and the hard part isn't starting that work, it's
    seeing it.
  

      

      

        

    One live view of everything you own: every machine, every terminal on it, what's running, who's
    watching, how long it's been idle. Attach, rename, spawn or kill a session on any box, from the CLI
    or the browser. Enroll a device as an owner once and it connects with no PIN: per-device trust,
    revocable one at a time.
  

      

      

        

    An agent can use the same door. Hand it a session ID and PIN and it connects like
    any other viewer, to every machine you've shared, triaging an incident on one box while it patches
    another, with you watching both in the same browser. Or skip the PIN entirely and give it the
    MCP server instead.
  

      

    

    

    

    

      

        
Restarts

        
A restart doesn't end the session.

        

    When a machine reboots, crashes or loses power, every session that was running comes back when
    you log in: the same link and PIN, what was on screen, and a shell in the folder you were
    working in.
  

      

      

        

    Your agents come back too, picking up their conversation. Claude Code, Codex,
    Cursor, Qwen, Gemini, OpenCode and pi carry on where they left off, with the options they were
    started with. A session you ended yourself stays ended.
  

      

    

    

    

    

      

        
Copy and paste

        
AirDrop for all your machines.

        

    reminal copy a file on one machine and it prints a short code. Run
    reminal paste with that code on any other, Mac, Linux or Windows, and the file
    lands there. No shared folder, no account, no ports to open.
  

      

      

        

    The code is the key. The file and its name are encrypted end to end; the relay
    passes on ciphertext it can't read. A code is good for one paste, while the machine you copied
    from holds it: an hour, unless you say otherwise.
  

      

    

    

    

    

      

        
Agent bus

        
Your agents can see each other.

        

    Claude Code on the laptop, Codex on the build box, a test suite on the Mini. Same problem, no
    shared anything. Every vendor's answer is subagents inside its own product, which is no help
    when the agents come from different vendors.
  

      

      

        

    reminal integrate registers reminal's MCP server with the agent CLIs
    you already have (Claude Code, Codex, Cursor, Gemini, OpenCode, Antigravity, Amp), and from then
    on the terminal is the bus. Nothing to adopt on the far side: if it runs in a PTY, it can
    be read and typed into, and it never knows anything is watching.

Security

  
As secure as a properly configured SSH, and safer by default.

  

    SSH leaves port 22 open and trusts you to configure everything correctly. reminal takes the
    opposite approach: nothing to expose, session secrets encrypted on disk.
  

  

    

      
No open ports

      
Your machine only dials out. There is nothing on the network to scan, brute-force or zero-day. That is the single biggest difference from exposing SSH to the internet.

    

    

      
Ephemeral credentials

      
The session ID and PIN exist only while reminal runs. Ctrl+C and they're gone forever. A stolen laptop grants nothing, because there is nothing left to steal.

    

    

      
End-to-end encrypted

      
AES-256-GCM under a fresh key per run, handed to each viewer through a PIN-authenticated X25519 handshake.

    

    

      
Relay-blind

      
The relay routes ciphertext it cannot read, and can't be used to brute-force the PIN offline.

    

    

      
Forward secret

      
Every connection runs its own ephemeral exchange, so recorded traffic stays unreadable.

    

    

      
Auditable, and yours

      
Every line is open source under AGPL-3.0, including the relay, which you can host yourself on Cloudflare in a few minutes.

    

    

      
Rate-limited at the source

      
Every PIN guess costs a full online handshake with your machine, answered at roughly six a minute. Exhausting a 6-digit PIN takes months; a session lives for hours.
