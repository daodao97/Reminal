Fixed
- Setting up a coding agent from a viewer now needs the owner device's
  signed approval, runs one at a time on a machine, and cannot be held up by
  a slow shell start-up. `reminal integrate` writes each agent's config in
  one piece, keeps the first backup it made instead of overwriting it, and
  now remembers when it set each agent up (`reminal integrate --check`).
