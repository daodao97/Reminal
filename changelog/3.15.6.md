# 3.15.6

Security
- This release strengthens how PIN connections and shared ports are
  protected. We recommend updating reminal on every machine you use.
- After updating, run `reminal repin --all` once on each machine to give
  your sessions fresh PINs. Devices you have added as owners are unaffected.
- Thanks to the community member who reported this.

Improved
- Connecting with a PIN has been updated. A machine still on an older
  version cannot be reached with a PIN until it is updated, and says so
  when you try. Devices you have added as owners connect as before.
- `reminal copy` codes are ten characters now, shown as `ABCDE-FGHJK`. Both
  the machine you copy from and the one you paste on need this version; a
  code from an older reminal is recognised and tells you what to do.
- A port you share now opens at its own address. Links you already shared
  keep working.

Added
- `reminal repin` gives a session a new PIN without ending it; `reminal repin
  --all` does every session on the machine. The old PIN and any link made
  with it stop working.
- A guided tour of the web viewer on your first visit. Replay it from the
  Host menu.
