# 3.14.24

Fixed
- A session running pi no longer shows as busy forever after its first
  turn. Some versions of pi signal the end of a run differently, and
  reminal was waiting for a signal those versions never send, so pi
  sessions looked stuck at "working" and anything queued for them in an
  org never arrived. Run `reminal integrate pi` once after upgrading to
  pick up the fix; `reminal integrate --check` will remind you.
