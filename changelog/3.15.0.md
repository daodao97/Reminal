# 3.15.0

Added
- Your sessions survive a restart. If your machine reboots, crashes or
  loses power, every session that was running comes back when you log in:
  the same link and PIN, everything that was on screen, and a shell in the
  folder you were working in.
- Your coding agent comes back too, on the same conversation. claude, codex,
  gemini, qwen, cursor-agent, opencode and pi are started again where they
  left off, with the options you started them with, such as skipping
  permission prompts or a chosen model. A prompt you gave on the command
  line is not sent a second time.
- Several of the same agent in one folder each get their own conversation
  back. When reminal cannot tell which conversation was whose, it opens the
  agent's own list so you pick, rather than guessing.
- Sessions you end yourself stay ended: `reminal kill`, `reminal stop`, or
  typing `exit` means the session is not brought back.
- `reminal restore` lists sessions a restart ended and brings one or all of
  them back by hand. Set `REMINAL_NO_RESTORE=1` to stop them coming back by
  themselves at login.

Fixed
- On Windows, starting a background session while offline failed after a
  15 second wait. It starts straight away now.
- On Windows, a session running a program such as claude showed its folder
  as C:\Windows instead of the folder you were in.
- Text read from a session by an agent no longer loses the spaces some
  programs draw on screen, so "trust this folder" no longer reads as
  "trustthisfolder".
