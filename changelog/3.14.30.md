# 3.14.30

Added
- A session now shows how many shells it still has running, next to what it
  is doing. A turn that has finished but left a build or a server going
  reads "done · 1 shell", so you can see there is still something alive
  before you decide it needs nothing from you.
- It shows up wherever you look at your sessions: the list in the terminal,
  the Machines panel, and on a phone, where the count folds in beside the
  state so the rows stay as narrow as they were.
