# 3.15.13

Fixed
- If the key that protects your saved sessions goes missing from disk while reminal is running, running sessions now put it back on their own, and nothing saved is set aside in the meantime. `reminal doctor` reports it, and `reminal doctor --repair-key` recovers it from a running session.
- `reminal doctor` now says when that key is kept in a file although your Mac or PC has a keychain, and that it moves there on its own.
