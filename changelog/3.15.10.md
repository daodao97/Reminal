# 3.15.10

Fixed
- Typing a wrong PIN at the prompt now offers another try, as it should.
- A machine that reconnects to a self-hosted relay is no longer kept out by a
  connection that never finished signing in.
- Reconnecting after a machine restarts no longer picks up a stale connection.
- `reminal integrate` no longer adds reminal's hooks twice to Claude Code after
  it has rewritten its settings, which made each hook fire more than once.

Improved
- Connection pacing keeps room for devices that have connected with the right
  PIN before, so a busy network is less likely to crowd them out.
- Shared ports and sessions clean up more reliably on the relay after a machine
  goes away.
- Antigravity sessions now show when they're working and when they're done.
