# 3.15.8

Improved
- Connections between viewers and machines use updated encryption. Update
  reminal on every machine you use; older and newer versions keep working
  together in the meantime.
- A device you have added as an owner now recognises your machine on all of
  its sessions, and asks once before connecting to a machine it has not
  connected to before.
- Shared ports, and machines that go offline for a while, reconnect more
  reliably.
