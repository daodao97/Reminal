# 3.14.23

Fixed
- After upgrading reminal, the setup check told you the pi coding agent was
  still good to go when it wasn't. Upgrading leaves pi's copy of reminal's
  extension on the old version, so recent improvements to it never reached
  you, and nothing said so. `reminal integrate --check` now notices and tells
  you to run `reminal integrate` again, which puts it right.
