# 3.14.22

Fixed
- A file you send to a computer with "auto-delete in 1h" now really does
  disappear, even if you close the session before the hour is up. Until
  now, closing the session quietly cancelled the deletion and the file
  stayed on that computer for good — so uploads have been piling up in
  your Downloads folder without you knowing.

Note
- Uploads from before this version were never recorded, so reminal cannot
  know when they were meant to go. They stay where they are: look in the
  reminal folder inside Downloads if you want to clear them out.
